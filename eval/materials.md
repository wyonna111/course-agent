## 课件覆盖的知识点汇总

### 第1章 嵌入式系统概论
- 冯·诺依曼结构与哈佛结构的区别
- 三总线：地址总线(AB)、数据总线(DB)、控制总线(CB)
- 运算器(ALU)、控制器、存储器（Cache/内存/外存）
- 数据编码：原码、反码、补码、移码、ASCII码
- 定点数与浮点数（IEEE754格式）
- 逻辑运算与移位操作
- 嵌入式系统的定义、特点与应用领域

### 第2章 8086微机系统原理和结构
- 8086 CPU：16位数据总线、20位地址总线、指令流水线
- 寄存器结构：通用寄存器(AX/BX/CX/DX)、指针变址寄存器(SP/BP/SI/DI)、段寄存器(CS/DS/SS/ES)、标志寄存器(PSW)
- 存储器分段：物理地址 = 段地址×16 + 偏移地址
- 7种寻址方式：立即/寄存器/直接/寄存器间接/寄存器相对/基址变址/相对基址变址
- 指令系统：MOV/PUSH/POP/ADD/SUB/MUL/DIV/AND/OR/JMP/CALL/INT/IRET等
- 中断系统：内部中断（INT n、除法错、单步、断点、溢出）和外部中断（NMI、INTR）

### 第3章 8086汇编语言程序设计
- 汇编程序模板：.MODEL SMALL / .8086 / .stack / .data / .code / .startup
- 伪指令：DB/DW/DD/EQU/=/SEGMENT/ENDS/PROC/ENDP/ASSUME/END
- 表达式运算符：算术(+ - * / MOD)、逻辑(AND/OR/XOR/NOT)、关系(EQ/NE/LT/GT/LE/GE)、分析(SEG/OFFSET/TYPE/LENGTH/SIZE)
- DOS功能调用(INT 21H)：键盘输入(1/7/8/0AH)、显示输出(2/9)
- 程序结构：顺序、分支(CMP+条件跳转)、循环(LOOP)、子程序(CALL/RET)

### 第4章 存储系统
- SRAM vs DRAM：双稳态触发器 vs 电容存储（需刷新）
- ROM类型：掩模ROM、PROM、EPROM、EEPROM、Flash（NOR/NAND）
- 存储器扩展：位扩展（增加字长）、字扩展（增加容量）、字位扩展
- 译码方式：全译码（地址唯一）、部分译码（地址重叠）、线性选择
- 8086存储器连接：奇偶分体（BHE和A0配合）

### 第5章 典型接口芯片
- 简单I/O：74LS244（单向缓冲）、74LS245（双向缓冲）、74LS373（锁存器）
- 8255A并行接口：方式0（基本I/O）、方式1（选通I/O）、方式2（双向）、控制字/C口位操作
- 8253定时/计数器：6种工作方式（方式0~5）、初始化（控制字+计数初值）
- 8251A串行通信：异步/同步模式、方式字/命令字/状态字、RS-232C标准
