# 测试用例清单 (`eval/test_cases.md`)

## 一、第1章 嵌入式系统概论（4题）

### TC-1.1 冯·诺依曼结构的数据与程序区分
**题目**：冯·诺依曼结构计算机的存储器中存储的数据和程序是怎样区分的？

**参考答案要点**：
- 程序和数据都以二进制形式存储，本身无区别
- CPU通过指令周期阶段区分：取指阶段读出的是指令，执行阶段读出的是数据
- 或通过地址来源区分：PC提供地址取出的是指令，指令地址码提供的是操作数

---

### TC-1.2 固件的定义与特点
**题目**：什么是固件？阐述它与软硬件之间的关系。

**参考答案要点**：
- 固件是固化在ROM里的程序，可通过特定程序升级
- 介于硬件和软件之间的实体，功能上类似软件，形态上是硬件
- 通常把固定不变的常用软件固化在硬件中成为固件

---

### TC-1.3 机器数转换（原码/补码/反码/无符号数）
**题目**：若寄存器内容为80H，当它分别代表原码、补码、反码和无符号数时，对应的十进制数各是多少？

**参考答案**：
| 表示方式 | 十进制值 |
|----------|----------|
| 原码 | -0 |
| 补码 | -128 |
| 反码 | -127 |
| 无符号数 | 128 |
| 带奇校验的无符号数 | 64 |

---

### TC-1.4 IEEE754单精度浮点数转换
**题目**：将十进制数 -10.625 转换为IEEE754标准的单精度浮点数规格化编码形式。

**参考答案**：
- 二进制：-1010.101 = -1.010101 × 2³
- S=1, E=3+127=130=10000010, M=01010100000000000000000
- **结果：11000001 01010100 00000000 00000000**（C1540000H）

## 二、第2章 8086微机系统（5题）

### TC-2.1 标志位的使用
**题目**：要完成下述运算或控制，用什么标志位判别？
（1）比较两数是否相等  （2）运算结果是正数还是负数
（3）两数相加是否溢出  （4）判断是否要补1（偶校验）
（5）两数相减后比较大小  （6）中断信号是否允许

**参考答案**：
| 场景 | 标志位 | 判断条件 |
|------|--------|----------|
| 两数相等 | ZF | ZF=1 |
| 正/负数 | SF | SF=0为正，SF=1为负 |
| 有符号溢出 | OF | OF=1溢出 |
| 无符号溢出 | CF | CF=1溢出 |
| 偶校验 | PF | PF=1不补1 |
| 中断允许 | IF | IF=1允许 |

---

### TC-2.2 物理地址计算与堆栈操作
**题目**：若SS=3500H，SP=0800H，堆栈段物理地址范围是多少？入栈10个字节后SP=？再出栈6个字节后SP=？

**参考答案**：
- 物理地址范围：35000H ~ 35800H
- 入栈10字节（减10）：SP = 0800H - 0AH = **07F6H**
- 再出栈6字节（加6）：SP = 07F6H + 06H = **07FCH**

---

### TC-2.3 寻址方式识别
**题目**：指出下列指令的源操作数和目的操作数的寻址方式
（1）MOV AX, 2408H    （2）MOV BX, [SI]
（3）MOV [BP+100H], AX

**参考答案**：
| 指令 | 目的操作数 | 源操作数 |
|------|------------|----------|
| MOV AX, 2408H | 寄存器寻址 | 立即寻址 |
| MOV BX, [SI] | 寄存器寻址 | 寄存器间接寻址 |
| MOV [BP+100H], AX | 寄存器相对寻址 | 寄存器寻址 |

---

### TC-2.4 内存读取与奇偶地址
**题目**：DS=7850H，数据1EE5H存放在偏移3121H，数据2A8CH存放在偏移285AH。读取这两个字各需几次总线操作？

**参考答案**：
- 1EE5H物理地址：78500H+3121H=7B621H（**奇地址**）→ **2次**总线操作
- 2A8CH物理地址：78500H+285AH=7AD5AH（**偶地址**）→ **1次**总线操作

---

### TC-2.5 中断向量表
**题目**：中断类型2的服务程序起始地址为0485H:0016H，在中断向量表中如何存放？

**参考答案**：
| 物理地址 | 内容 |
|----------|------|
| 00008H | 16H |
| 00009H | 00H |
| 0000AH | 85H |
| 0000BH | 04H |

## 三、第3章 汇编语言程序设计（3题）

### TC-3.1 数据定义与存储分配
**题目**：下列语句分配多少字节空间？
```assembly
VAR1 DB 10,2
VAR2 DW 2 DUP(?), -1
VAR3 DB 'SeeU','S'
VAR4 DD 1
```

**参考答案**：
| 变量 | 字节数 |
|------|--------|
| VAR1 | 2 |
| VAR2 | 6 |
| VAR3 | 5 |
| VAR4 | 4 |
| **总计** | **17字节** |

---

### TC-3.2 寄存器内容分析
**题目**：已知数据段如下，求指令执行后的结果
```assembly
DATA SEGMENT
    A DB 'A',10H
    B DB 'COMPUTER'
    X DW 1234H,0FFH
    Y DB 5 DUP(?)
DATA ENDS
```
```assembly
MOV AL, A      ; AL=?
MOV DX, X      ; DX=?
MOV BX, OFFSET B ; BX=?
```

**参考答案**：
- MOV AL, A → **AL=41H**（'A'的ASCII码）
- MOV DX, X → **DX=1234H**
- MOV BX, OFFSET B → **BX=0002H**

---

### TC-3.3 循环与条件判断程序设计
**题目**：从BUF开始的15个字节型数据中，将负数送到MINUS单元。补全代码。

**参考代码**：
```assembly
    MOV CX, 15
    MOV SI, OFFSET BUF
    MOV DI, OFFSET MINUS
NEXT1:
    MOV AL, [SI]
    CMP AL, 0
    JGE NEXT2
    MOV [DI], AL
    INC DI
NEXT2:
    INC SI
    LOOP NEXT1
```

## 四、第4章 存储系统（3题）

### TC-4.1 存储器芯片地址/数据线计算
**题目**：计算以下芯片的地址线和数据线数量
（1）2K×16  （2）64K×8  （3）16M×32  （4）4G×4

**参考答案**：
| 芯片 | 地址线 | 数据线 |
|------|--------|--------|
| 2K×16 | 11 | 16 |
| 64K×8 | 16 | 8 |
| 16M×32 | 24 | 32 |
| 4G×4 | 32 | 4 |

---

### TC-4.2 存储器扩展计算
**题目**：用1024×1位的RAM芯片组成16K×8位的存储器，需要多少芯片？片内寻址需要多少地址线？片选需要多少地址线？

**参考答案**：
- 芯片数量：(16K×8) ÷ (1K×1) = **128片**
- 片内寻址：1024=2¹⁰ → **10根**
- 片选信号：16组需要16个片选 → **4根**（经译码器）

---

### TC-4.3 存储器地址范围设计
**题目**：用8K×8的EPROM2764设计64K×8存储器，地址范围40000H~4FFFFH，需要几片？片内寻址需要多少地址线？

**参考答案**：
- 需要片数：64K÷8K = **8片**
- 片内寻址：8K=2¹³ → **13根地址线**（A12~A0）
- 片选译码：8片需要**3根**（A15~A13接138译码器）

## 五、第5章 接口芯片（5题）

### TC-5.1 8253定时器初值计算
**题目**：8253时钟2MHz，要产生周期10μs的对称方波（方式3），计数初值是多少？

**参考答案**：
- 时钟周期 T_CLK = 1/2MHz = 0.5μs
- 计数初值 N = 10μs / 0.5μs = **20**

---

### TC-5.2 8253最低输出频率
**题目**：8253外部时钟512kHz，最大计数初值65536（0），能产生的最低频率是多少？

**参考答案**：
- f_out = f_clk / N = 512kHz / 65536 = **7.8125 Hz**

---

### TC-5.3 8255A初始化编程
**题目**：8255端口地址0A380H(A口)、0A382H(B口)、0A384H(C口)、0A386H(控制口)，工作方式0，A/B口输出，将PC4置0、PC7置1。

**参考代码**：
```assembly
; 方式控制字
MOV DX, 0A386H
MOV AL, 10000000B  ; A/B/C口全部输出，方式0
OUT DX, AL

; PC4置0
MOV AL, 00001000B
OUT DX, AL

; PC7置1
MOV AL, 00001111B
OUT DX, AL
```

---

### TC-5.4 异步串行通信字符数计算
**题目**：异步传输，1个起始位、7个信息位、1个奇偶位、1个停止位，波特率9600bps，每秒最大传输字符数？

**参考答案**：
- 每字符位数：1+7+1+1 = 10位
- 字符数 = 9600 ÷ 10 = **960 字符/秒**

---

### TC-5.5 汉字传输时间计算
**题目**：波特率1200，无校验位，1个停止位，8位数据，传输5000个汉字（每汉字2字节），需多长时间？

**参考答案**：
- 每字符位数：1+8+1 = 10位
- 每秒字符数：1200÷10 = 120字符/秒 = 60汉字/秒
- 传输时间：5000 ÷ 60 ≈ **83.33秒**
